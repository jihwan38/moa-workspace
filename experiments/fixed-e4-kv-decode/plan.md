# Sole fixed-E4 decode device port

Base q022 `98662213`, actual physical pool axis Rc32. Device-only modules; all
original source and host policy remain untouched. E2e owns host metadata and
scalar/shared utilities; round2 owns prompt device paths. Reuse tail256-model
target, but every build uses a unique FURIOSA_OPT_OUT_DIR to avoid stale constant
dependencies. Root alone dispatches Arena.

B16 uses the proven 4bf039b2 explicit Main E4 LUT→BF16 DM reader and BF16→F32→E4
append; add complete live1..16 and standalone commit/reader entrypoints. R32 and
R64 current1024/512/mixed/HeadRows/768 readers retain their original arithmetic,
partial/reduction order and inactive64-row output handling. Only pool dtype and
gathered local K/V dtype change; decode E4 to BF16 before the original consumer.
Prefix768 upper512-row byte increment changes2097152→1048576; no other logical
mask/index semantics change. E4 ring bytes2097152, token bytes2048. Metadata
byte offsets are generated by the host, never implicitly mixed with BF16.

Compatibility: all Q, headed K/V, attention and O scratch remain BF16. q022
heads already round K/V; append recoding must prove exact idempotence, including
signed zero. Full-attention caches remain BF16. ActualRc32 tests replace archived
Rc64 synthetic layouts; all live-prefix/short-group policies and full cache
poison/immutable checks precede host activation. Direct64-live commit symbol is
preserved for type compatibility but current independentRc32 owners cannot
select it; paddedR64/R32 uses existing B16 segment commits.

Gates: source inverse-transform equality for unchanged arithmetic; host typecheck;
owned fresh-cache resource compile; actual codec/wholepool/intended-reader gates
with finite extremes, wrap, sparse slots0/15/16/31, live1..32, prefix512/768/mixed
policies, inactiveNaNs and signedzero; complete same-current graph timing where
applicable. No nativeQK approximation, no mask/reduction change, no serving claim
from resource success.
