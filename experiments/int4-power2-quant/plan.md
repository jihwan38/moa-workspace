# New A4 power-of-two arithmetic gate

Base394d60a2. This is a new approximate quantizer, not a tolerance repair for archived amax/7 DivF failures. Input contract is finite BF16. Let a=max(max(abs(x after F32-FTZ)),2^-112). Select the smallest power2 scale s satisfying7s>=a. Code is nearest integer with ties away fromzero ofx/s, clamped[-7,7]. Because s and reciprocal are exact normal powers2 over the entire finiteBF16 domain, the device multiplies by reciprocal; it never executes DivF or casts toI4. Output ordinaryI32 codes later feed the separately hardware-validated nibble pack.

Integer scale expression uses positiveF32 bits b: `((b+0x001fffff)&0x7f800000)-0x01000000`. It increments the base exponent iff mantissa>1.75, then subtracts2. Reciprocal bits are0x7f000000−scale_bits. The CPU proof uses independent rational comparisons, not this bit expression: all32,640 finite absoluteBF16 patterns and8,375,520 admissible signedBF16/power2 combinations pass. This is CPU arithmetic proof, not device proof.

Row scale is selected for the first independent device gate because it keeps the existing integer-dot reconstruction ABI and only16 scales. A960-block scale would require64scales forH3840 or256 forL15360 plus perKpartial scaling before floating-point reduction. Genericfixture comparisons in cpu-proof.json show lower error forblock960, but substantial A4 error remains and these are not suppliedmodel activations. No modelquality claim is made. Suppliedweight stratified row reconstruction errors may be reported by the eventual device probe without using them to fit parameters.

Resource budget: each live row holds7,680B BF16 input and15,360B I32 output, plus32Bscale/reciprocal state. Two clusters each own8 live rows. The output HBMcode transfer is245,760B and scales64B. These costs and subsequent30,720B packedoutput must be included in any complete-chain timing; no hidden packing or dataflow is free. Firstgate is complete quantizer code/scale oracle, then pack/rawconsumer composition by coordination. No serving/default or weight quantization changes.
