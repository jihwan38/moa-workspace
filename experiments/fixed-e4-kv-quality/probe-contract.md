# Fixed E4 numerical surrogate diagnostic contract

`ENABLED=false` keeps production math; the separate ON source will change only this constant. Both artifacts must be captured immediately with fresh-package provenance. Each program logs its flag and verifies physical32 owning KV buffer sizes (12,884,901,888 bytes) before model work. No approximate F4 FFN or LM shadow is imported.

- `test_fixed_e4_head_codec heads 0` checks the unconditional finite codec in B16/R64/P128 DM shapes, then eight current head entrypoints against the unchanged scalar head oracle plus independent CPU codec. `scalar 0` checks canonical and legacy scalar producers, Q and every pool byte at slot31/wrap/reset. OFF proves baseline identity plus unconditional helper; ON is required to prove hooked producers.
- `compare_fixed_e4_kv model 512` (also1024) computes 16 independent histories twice in disjoint physical halves. Same scalar/B16 routes, activeP128, resets, ordinary fallback and reentry, own device selection, all vocabulary and complete caches must match. Nothing is called an unchanged original route when ON.
- `compare_fixed_e4_kv r32 512` (also1024) recomputes 17 histories twice on the same coordinates, then scalar→17→17→8 transitions. Every returned logit must match. This mode does not independently snapshot all cache bytes; the disjoint16 and packed modes provide strict cache coverage.
- `compare_fixed_e4_kv partial 896` (also0/128/1024) computes matching native128 history, explicitly selects tiled Wide17/31, then ordinary B16prompt16/scalar1 and an ordinary BF16-QKV P128 reset. Full logits and complete cache bytes are strict.
- `compare_fixed_e4_packed CASE INTERLEAVE` uses the existing physical32 11-route oracle: quad, same-owner512, pair256+256, tails256/384 with one/two/three owners, and three-owner512 placements. Two disjoint arms use identical kernels/defaults and prefix histories. Case0 optionally interleaves22 paired decoder slots; reset reverses the live prompt allocation order and poisons dense padding. All logits, owner caches and untouched sentinel pair are compared. One case per bounded invocation.

Cross-program comparison is **only** full-vocabulary finiteness, top1, seeded own-output sample IDs, full sum/L1/squared-L2/min/max, a noncryptographic FNV64 checksum, and128 fixed indexed BF16 samples. A checksum equality is not a full-byte proof; sampled drift is not an all-element error norm. Same-program replay separately reads and compares every output and uses exact seeded stochastic sampling. Public task quality remains required. Timings include surrogate conversion over BF16 storage and do not estimate compressed-cache speed.
